الـ string مبيتغيّرش — كل += بيخلق واحد جديد

Strings, Immutability and StringBuilder
1

ليه الدرس ده مهم؟

كتبت تصدير CSV لعشرة آلاف صف بـ csv += line + "\n". شغّال تمام على ١٠٠ صف في التست، وعلى الإنتاج بقى بياخد ٤٠ ثانية والـ CPU طالع فوق. مغيرتش أي منطق — بس عدد الصفوف زاد.

في .NET الـ string immutable: مفيش حاجة اسمها «عدّل النص». كل += بيعمل نص جديد بالكامل وينسخ القديم جوّاه. يعني في لوپ عدد النسخ بيبقى 1+2+3+…+n ≈ O(n²)، والقديم كله بيتحوّل زبالة للـ GC.
لو مش فاهمه: كودك هيبقى O(n²) وإنت شايفه لوپ عادية، والـ Gen0 collections هتفضل تزيد، والذاكرة تطلع وتنزل من غير سبب واضح.

مثال واقعي من شغلك

// ❌ تصدير CSV بـ += — O(n²) نسخ
var csv = "";
foreach (var o in orders)             // 10,000 صف
    csv += $"{o.Id},{o.Total}\n";      // ≈ 4 GB نسخ إجمالي، ثواني

// ✅ نفس النتيجة بالظبط
var sb = new StringBuilder(orders.Count * 24);  // احجز السعة لو تعرفها
foreach (var o in orders)
    sb.Append(o.Id).Append(',').Append(o.Total).Append('\n');
var csv = sb.ToString();               // نسخة واحدة في الآخر، ملي ثانية
مش كل دمج محتاج StringBuilder: a + b + c في سطر واحد بيتحوّل من الكومبايلر لـ string.Concat(a, b, c) = نسخة واحدة. الـ StringBuilder بيكسب في اللوپات وبس. 
// المقارنة: مقارنة نصوص من غير ما تعمل نسخ جديدة
if (name.ToUpper() == "ADMIN")                       // ❌ بيخلق string جديد كل مرة
if (name.Equals("admin", StringComparison.OrdinalIgnoreCase))  // ✅ صفر تخصيص

// التقطيع: Substring بينسخ، AsSpan لأ
var part = line.Substring(0, 8);                     // ❌ نسخة جديدة كل استدعاء
ReadOnlySpan<char> part2 = line.AsSpan(0, 8);        // ✅ نافذة على نفس الذاكرة

غلطات بتحصل كتير

  • += جوّه لوپ — أشهر O(n²) مخفي في .NET. أي دمج جوّه for/foreach = StringBuilder.
  • StringBuilder لدمج تلاتة نصوص — أبطأ وأتقل من $"{a}{b}{c}". استخدمه في اللوپات بس.
  • ToUpper()/ToLower() للمقارنة — تخصيص زيادة وسلوك غلط مع لغات معينة. الصح StringComparison.OrdinalIgnoreCase.
  • نسيان السعة الابتدائية — new StringBuilder(capacity) بيوفّر توسيعات ونسخ.
  • الظن إن s.Replace(...) بيغيّر s — لأ، بيرجّع نص جديد. لازم تسند الناتج.

اختبر نفسك

1. لوپ فيها ١٠٠٠ تكرار بتعمل s += "x". تعقيد النسخ الإجمالي؟
كل تكرار بينسخ الطول الحالي كله: 1+2+3+…+n ≈ n²/2.
2. var full = first + " " + last; — تستبدله بـ StringBuilder؟
الدمج في تعبير واحد بيتجمّع في استدعاء Concat واحد. الـ StringBuilder هنا تعقيد زيادة.

الخلاصة في ٣ نقاط

  1. الـ string ثابت (immutable): كل تعديل = نص جديد + نسخ الكل.
  2. دمج جوّه لوپ = StringBuilder (ويفضّل بسعة ابتدائية). دمج في سطر واحد = سيبه زي ما هو.
  3. للمقارنة استخدم StringComparison، وللتقطيع الكتير استخدم AsSpan بدل Substring.
